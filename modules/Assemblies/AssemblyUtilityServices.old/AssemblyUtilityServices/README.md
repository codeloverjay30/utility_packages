# Description
Utility Class to more easily to get the metadata of assembly.

# Features
## 1.0.0-preview-1.0.0
### Added
+ Get the information of assembly, such as version, name, etc.

## 1.1.0-preview-1.0.0
### Added
+ more easily to get the following metadata of assembly:

    - strong name of an assembly
    
    - short name of an assembly

## 1.2.0-preview-1.0.0
### Added
+ Get path of all assemblies of specified path.

+ Load all assemblies of specified path.
