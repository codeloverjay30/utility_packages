# Description
Service to access all available uninstallable app via `Registry keys`.

# Note
+ It can't be a class library since it gets value from `Registry keys` on Windows.

+ It is only supported on `Windows 10/11` or above.

# Prequisite
+ These one of following terminal can work:

    - `DOS`
